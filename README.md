# SmetaPilot

Универсальный мастер коммерческих строительных смет: пользователь описывает работу обычным текстом, уточняет несколько важных параметров и получает редактируемую смету с прозрачными формулами.

## Возможности первой версии

- 16 направлений строительства с отдельными наборами параметров и статей;
- AI-разбор описания через Cloudflare Workers AI;
- локальный резервный анализатор при отсутствии сети или недоступности AI;
- детерминированные расчёты без арифметики внутри LLM;
- ручное редактирование позиций, количества и цен;
- явные источники значений: пользователь, формула, типовое значение или поиск;
- локальное сохранение черновика;
- экспорт в PDF и XLSX;
- адаптивный PWA-интерфейс.

Дорожный модуль рассчитывает выемку грунта, геотекстиль, песчаный и щебёночный слои, асфальтобетон, бордюры, технику и количество рейсов. Плотности и коэффициенты запаса доступны в точной настройке.

## Запуск

```bash
npm install
npm run dev
```

Для AI-разбора во втором терминале:

```bash
npx wrangler dev
```

Vite проксирует `/api` на локальный Worker. Без Worker интерфейс автоматически использует локальное распознавание.

## Проверка и деплой

```bash
npm run check
npm run build
npm run worker:types
npm run worker:check
npm run test:road
npm run deploy
```

`wrangler deploy` публикует интерфейс и API единым Cloudflare Worker со Static Assets. GitHub Action отдельно публикует статический резервный интерфейс на GitHub Pages.

## Принцип расчёта

Workers AI только классифицирует описание и извлекает явно названные параметры. Объёмы и итоговые суммы считает TypeScript-движок по проверяемым формулам. Типовые значения всегда отмечаются и не маскируются под пользовательские данные.

> SmetaPilot формирует коммерческий предварительный расчёт. Нормативные сметы по государственным базам и индексам планируются отдельным профессиональным модулем.
